# gall_rs

## Описание
Веб-приложение онлайн-галереи на языке Rust. Создано на основе собственной реализации HTTP-сервера.

## Возможности
- [x] Создать/войти в учетную запись, выйти из учетной записи
- [x] Просмотреть галерею пользователя по ссылке
- [ ] Загрузить изображение на сервер, удалить с сервера
- [ ] Редактировать информацию о профиле
- [ ] Редактировать информацию об изображении
- [ ] Загрузить видео-файлы
